# Current publication figures

This directory is the curated home for the most recently generated publication figures in the commitment-horizon study.

- `build_ipccc_bundle_length_figures.m` regenerates the two bundle-length figures and their validation record from repository-relative study data.
- Each figure is provided as a 300-dpi PNG, vector PDF, and editable MATLAB FIG.

Run either bundle-length MATLAB script from any working directory; paths are resolved from the script location.
